**The Last Account · 1.4**

A self-contained CRT roguelike / match-3 dungeon crawler by **Splarg**.

**Play on itch.io:** https://splarg.itch.io/atventurerer

## Current release

Version **1.4** — 19 September 2026.

The game lives entirely in the root `index.html`: HTML, CSS, JavaScript, chiptune music and sound effects, with no external assets required.

### Features

- Story mode: **The Last Account**, a ten-floor campaign with choices, journal pages and multiple endings
- Classic and Endless modes
- Match-3 combat with enemy intent, shields, dodge, status effects and boss fights
- Relics and a two-spell loadout
- Treasure vaults and wandering merchants
- Keyboard, mouse, touch and swipe controls
- Story autosave / Continue
- Local high-score Hall of the Fallen

## Source status

The root `index.html` is the current **1.4** release source.

Earlier published states remain recoverable through Git history. Future development should be committed after this release snapshot so the shipped version stays identifiable.

## Technology

HTML5 / CSS / JavaScript. No build step.
